Usuario Propiedades

El tipo Usuario expone a los siguientes miembros.

Propiedades
 NombreDescripción
DNIDocumento Nacional de Identidad (almacenado cifrado).
EmailDirección de correo electrónico.
EstadoEstado del usuario (Activo, Inactivo, Bloqueado).
FamiliasObtiene todas las familias asignadas al usuario, incluyendo las anidadas.
FechaRegistroFecha en que se registró el usuario.
HabilitadoIndica si el usuario está habilitado (Estado == "Activo").
IdUsuarioIdentificador único del usuario.
NombreNombre completo del usuario.
PasswordHash de la contraseña del usuario.
PatentesObtiene todas las patentes del usuario, recorriendo la jerarquía de familias.
PrivilegiosLista de privilegios asignados al usuario (familias y patentes).
RolRol del usuario (Admin, Comercio, Cliente).
TelefonoNúmero de teléfono de contacto.
