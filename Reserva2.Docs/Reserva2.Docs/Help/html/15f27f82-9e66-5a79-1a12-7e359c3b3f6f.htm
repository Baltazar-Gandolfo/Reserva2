LoggerService Métodos

El tipo LoggerService expone a los siguientes miembros.

Métodos
 NombreDescripción
Debug(String) Registra un mensaje de depuración.
Debug(String, Exception) Registra un mensaje de depuración con excepción.
Error(String) Registra un mensaje de error.
Error(String, Exception) Registra un mensaje de error con excepción.
Fatal(String) Registra un mensaje de error fatal.
Fatal(String, Exception) Registra un mensaje de error fatal con excepción.
Info(String) Registra un mensaje informativo.
Info(String, Exception) Registra un mensaje informativo con excepción.
Warn(String) Registra un mensaje de advertencia.
Warn(String, Exception) Registra un mensaje de advertencia con excepción.
