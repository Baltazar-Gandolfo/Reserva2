UsuarioService Métodos

El tipo UsuarioService expone a los siguientes miembros.

Métodos
 NombreDescripción
AgregarFamilia Asigna una familia (rol compuesto) a un usuario.
AgregarPatente Asigna una patente (permiso) a un usuario.
BuscarPorEmail Busca un usuario por su dirección de email.
CambiarEstado Cambia el estado de un usuario (Activo, Bloqueado, etc.).
CambiarPassword Cambia la contraseña de un usuario.
GetAll Obtiene todos los usuarios del sistema.
QuitarFamilia Quita una familia (rol compuesto) de un usuario.
RegistrarUsuario Registra un nuevo usuario en el sistema.
