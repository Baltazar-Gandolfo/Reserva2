El tipo ReservaBLL expone a los siguientes miembros.

Métodos
 NombreDescripción
Cancelar Cancela una reserva aplicando la política de cancelación para determinar si corresponde reembolso. Libera el slot y notifica al primero de la lista de espera.
Confirmar Confirma una reserva pendiente. Solo puede ser ejecutado por Comercio o Admin.
EqualsDetermines whether the specified object is equal to the current object.
(Se hereda de Object)
ExpirarVencidas Expira las reservas pendientes que superaron su tiempo límite de pago. Libera los slots y notifica a la lista de espera por cada una.
FinalizeAllows an object to try to free resources and perform other cleanup operations before it is reclaimed by garbage collection.
(Se hereda de Object)
GetHashCodeServes as the default hash function.
(Se hereda de Object)
GetTypeGets the Type of the current instance.
(Se hereda de Object)
HayPendientes Verifica si existen reservas pendientes de pago en el sistema.
ListarDelComercio Obtiene las reservas de un comercio con filtros opcionales. Solo para Admin o dueño del comercio.
ListarMisReservas Obtiene las reservas del usuario actualmente logueado, expirando las vencidas previamente.
ListarVisibles Obtiene las reservas visibles para el usuario actual según su rol: Cliente ve las propias, Comercio/Admin ve las de sus comercios.
MemberwiseCloneCreates a shallow copy of the current Object.
(Se hereda de Object)
ObtenerPorId Obtiene una reserva por su identificador, validando permisos del usuario actual.

Reservar Realiza una reserva sobre un slot de disponibilidad. Valida disponibilidad del elemento, límite semanal de reservas y bloquea el slot de forma concurrente.
