 ClaseDescripción
CBU Representa una Clave Bancaria Uniforme asociada a un comercio para recibir pagos.
Comercio Representa un comercio registrado en el sistema de reservas.
Disponibilidad Representa un slot de disponibilidad horaria de un elemento reservable.
ElementoReservable Representa un elemento que puede ser reservado (cancha, sala, mesa, etc.).
EstadisticaDiaria Representa una estadística diaria de un elemento reservable.
ListaEspera Entrada en la lista de espera de un slot de disponibilidad.
LogAuditoria Registro de auditoría (bitácora) del sistema.
LogError Registro de error del sistema almacenado en la tabla LogError.
Notificacion Representa una notificación enviada a un usuario del sistema.
Pago Representa un pago asociado a una reserva.
ReglaDisponibilidad Regla de disponibilidad que define los horarios semanales de un elemento reservable.
ReglaNegocio Regla de negocio configurable por comercio (clave-valor).
Reserva Representa una reserva realizada por un usuario sobre un slot de disponibilidad.
Sena Representa una seña (pago parcial anticipado) asociada a un pago.
Sucursal Representa una sucursal física de un comercio.
Usuario Representa un usuario del sistema con sus datos personales y credenciales.
